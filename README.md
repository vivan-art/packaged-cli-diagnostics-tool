# Packaged CLI Diagnostics Tool

A distributable Python command-line tool that inspects a machine and produces a human-readable report or structured JSON.

## Features

- Python version inspection
- Disk-space inspection
- Environment-variable inspection
- Developer-tool detection
- Useful exit codes
- JSON output
- Human-readable report
- Unit tests for success and error cases
